# Cómo colaborar con el Observatorio Cultural Independiente

El OCI recibe aportes documentales, observaciones territoriales, revisiones, datos, testimonios autorizados, fotografías, traducciones y propuestas de investigación.

Colaborar no implica disponibilidad permanente ni obligación de aceptar nuevas tareas.

## Modalidades de participación

### Aporte puntual

Entrega concreta de una fuente, fotografía, contacto, corrección o documento. Se acuerdan atribución, condiciones de uso y privacidad antes de su publicación.

### Observación territorial

Registro situado con objetivo, plazo y dedicación estimada. Puede consistir en una ficha, breve informe, seguimiento o identificación de fuentes.

### Coautoría

Corresponde cuando existe una contribución intelectual sustantiva al diseño, análisis, interpretación o redacción. La coautoría no se concede únicamente por apoyo general, posición institucional o acceso a información.

### Servicio profesional

Investigación, diagnóstico, taller, curaduría, archivo, edición u otra prestación realizada con presupuesto y condiciones acordadas.

## Acuerdo mínimo antes de comenzar

Cada colaboración debe indicar por escrito:

- objetivo y entregable;
- fecha o duración;
- dedicación estimada;
- persona de contacto;
- condición voluntaria, remunerada o de intercambio;
- créditos o autoría;
- licencia y uso de materiales;
- tratamiento de información sensible;
- posibilidad de retirarse.

## Límites de trabajo

- No hay guardias informales ni obligación de responder fuera de lo acordado.
- Las urgencias deben justificarse y aceptarse expresamente.
- El crédito no sustituye el pago cuando existe presupuesto para remunerar el trabajo.
- No se solicitará trabajo especulativo extenso como requisito para considerar una colaboración.
- Una persona puede rechazar tareas sin perder el reconocimiento por aportes anteriores.

## Flujo de contribuciones en GitHub

Para cambios técnicos o editoriales:

1. Abrir un issue que describa propósito, alcance y archivos afectados.
2. Trabajar en una rama separada.
3. Abrir un pull request con explicación y comprobaciones realizadas.
4. Solicitar revisión cuando el cambio afecte metodología, identidad, seguridad o datos.
5. Integrar solo después de resolver observaciones.

## Atribución

Los créditos deben reflejar la contribución real. Según corresponda, se utilizarán categorías como autoría, coautoría, revisión, documentación, fotografía, traducción, curaduría, testimonio o apoyo editorial.

## Conducta y cuidados

No se toleran hostigamiento, discriminación, amenazas, apropiación de autoría, exposición injustificada de datos ni presiones para trabajar fuera de los acuerdos.

Para proponer una colaboración: contacto@observatorioculturalindependiente.org
